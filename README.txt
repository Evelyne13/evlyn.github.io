# Personal Web - Evelyne

File:
- `index.html` = struktur website
- `style.css` = desain, warna, layout, typography
- `favicon.svg` = favicon
- `profile.jpg` = foto profil yang perlu kamu masukkan sendiri

## Cara menjalankan
1. Masukkan foto kamu ke folder ini.
2. Rename foto menjadi `profile.jpg`.
3. Buka `index.html` di browser.

## Untuk GitHub Pages
Upload semua file ke repository GitHub kamu, lalu aktifkan:
Settings → Pages → Deploy from a branch → main → / (root).

Elemen tugas yang sudah dimasukkan:
1. HTML Picture
2. HTML Favicon
3. HTML Link
4. HTML Heading
5. HTML CSS
6. Background / Color Text
7. Align
8. Font
9. Date and Time
10. HTML Table
